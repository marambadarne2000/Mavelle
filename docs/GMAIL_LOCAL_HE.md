# שליחה אמיתית דרך Gmail — ניסוי מקומי

החיבור המקומי משתמש ב־`smtp.gmail.com:587` עם STARTTLS ואימות. הוא דורש כתובת Gmail וסיסמת אפליקציה תקפה של אותה כתובת. לפי [Google](https://support.google.com/accounts/answer/185833), סיסמת אפליקציה מחייבת אימות דו־שלבי ואינה זמינה בכל סוג חשבון. Google מעדיפה OAuth כשיש תמיכה בו; החיבור הזה מיועד לניסוי מקומי מוגבל. [הגדרות SMTP הרשמיות](https://support.google.com/mail/answer/7104828).

## הפעלה

מתיקיית הפרויקט, ב־PowerShell 7:

```powershell
./scripts/Setup-Gmail.ps1 -Restart
```

1. מזינים בחלון המקומי את כתובת Gmail השולחת. הודעת הבדיקה נשלחת כברירת מחדל לאותה כתובת; אפשר להגדיר נמען אחר באמצעות הפרמטר `-Recipient`.
2. מזינים סיסמת אפליקציה בת 16 תווים בשדה מוסתר. אין להשתמש בסיסמת החשבון הרגילה או לשלוח סיסמה בצ׳אט. רווחים בין קבוצות התווים מוסרים לפני השימוש.
3. מאשרים משלוח של הודעת בדיקה אחת באמצעות `YES`, `yes`, `y` או `כן`. ללא אישור לא נשלחת הודעה ולא נשמרים פרטי התחברות.
4. כתובת האתר לקישורי אימות/שחזור מוגדרת אוטומטית לניסוי המקומי; אפשר לשנותה באמצעות `-PublicUrl`. ברירת המחדל `http://127.0.0.1:5173` פועלת רק במחשב הזה; פתיחת הקישור בטלפון אינה פותחת את השרת שבמחשב. משתמשים חיצוניים זקוקים לכתובת HTTPS ציבורית.
5. הסיסמה נשמרת מוצפנת באמצעות Windows DPAPI בתוך `.runtime/mail-config/settings.clixml`, עם הרשאות תיקייה למשתמש Windows הנוכחי ול־SYSTEM. הקובץ אינו נשלח ל־GitHub ואינו מיועד להעתקה לשרת ציבורי/משתמש Windows אחר.
6. `Start-Local.ps1` טוען את ההגדרות בעת הפעלת השרת ומחזיר את סביבת PowerShell למצבה הקודם מיד לאחר יצירת התהליך. הסיסמה אינה עוברת כארגומנט פקודה ואינה מודפסת.
7. לאחר הפעלה מחדש בודקים ש־`/api/auth/options` מחזיר `deliveryMode: smtp`. עדיין יש לבדוק בפועל את תיבת הדואר וספאם: אישור SMTP אינו הוכחת הגעה לתיבת Inbox.

ההתקנה אינה יוצרת לקוחות או עסקים, אינה משנה את סיסמת המנהלת ואינה מפעילה אוטומטית מדיניות אימות דוא״ל מחייב. לפני הפעלת מדיניות מחייבת יש לוודא שגם לחשבון המנהלת כתובת אמיתית מאומתת.

## מה נשלח מהמערכת

החיבור משמש בקשות אימות כתובת, שחזור סיסמה ושינוי כתובת באמצעות המסכים הקיימים. אין כאן דיוור שיווקי, הודעות על כל שינוי הזמנה או שליחה אוטומטית של כל אירוע במרכז העדכונים. הודעת הבדיקה היא הודעת בדיקת תעבורה בלבד ואינה יוצרת חשבון.

## הפרדת בדיקות

`Check.ps1`, בדיקות Selenium המבודדות ותרגיל השחזור כופים מסירה לקובץ ומנקים פרטי SMTP מסביבת תהליכי הבדיקה. כך בדיקות עם כתובות פיקטיביות אינן משתמשות בחשבון Gmail האמיתי. `Test-MailSettings.ps1` בודק הצפנה, פענוח וכתובות קישור בלי לשלוח אימייל.

אם ההתקנה בוטלה או ש־Gmail סירבה לשליחה, אין להציג את השירות כמחובר. מצב ההתקנה הלא־סודי נמצא בקובץ המקומי `.runtime/mail-setup-status.json`; אין בו כתובות, סיסמה או תוכן הודעות.
