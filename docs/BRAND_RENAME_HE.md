# שינוי שם המערכת ל־Mavelle

06.11.2026: שם המוצר והמותג הוחלף מ־Maramigo ל־**Mavelle**, לפי בחירת המשתמשת.

עודכנו שם האתר ב־header/footer, כותרת ותיאור הדפדפן, מסכי לקוח/עסק/מנהלת/עובד, קופה, אבטחת חשבון, תמיכה ועדכונים, תרגומי עברית/ערבית/אנגלית, כותרות אימייל, שם קובץ ייצוא החשבון ותיעוד הפרויקט. המותג מוצג באותיות לטיניות גם בממשק עברי/ערבי. הוסר סימון ®; לא נטען שהשם רשום כסימן מסחר.

שמות טכניים קיימים נשמרו לצורך תאימות: תיקיית הפרויקט, כתובת מאגר GitHub, Java packages, שם מסד הנתונים, migrations היסטוריות, מפתחות שמירת שפה/סל/קופה ואירועים פנימיים. מזהי הזמנות וחשבונות לא שונו. מזהה ההצפנה `Maramigo-MFA-v1` נשמר בכוונה כדי שסודות MFA קיימים ימשיכו להיפתח.

הגדרות TOTP חדשות נושאות את השם Mavelle. תווית שכבר נשמרה באפליקציית אימות חיצונית אינה משתנה אוטומטית, אך קודיה נשארים תקפים. צילומי מסך היסטוריים עשויים להציג את השם הקודם.

שינוי המיתוג אינו בדיקת זמינות דומיין או סימן מסחר, ואינו שינוי הרשאות המאגר או פרסום לציבור.
